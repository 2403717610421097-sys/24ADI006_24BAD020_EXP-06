# Implementation of LSTM for Sentiment Analysis

This experiment implements a Long Short-Term Memory (LSTM) network for sentiment analysis using the IMDB Movie Reviews dataset. The main objective is to classify movie reviews as positive or negative using Natural Language Processing and deep learning techniques. The dataset is prepared by converting reviews into numerical sequences, applying tokenization and sequence padding, and dividing the data into training, validation, and testing sets. An Embedding layer is used to convert the words into numerical vector representations, followed by an LSTM layer to learn important sequential patterns from the reviews. A Dense layer with sigmoid activation is used to classify the reviews into positive or negative sentiment. The model is trained using the Adam optimizer and binary cross-entropy loss function. After training, the model is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix. Accuracy and loss graphs are also plotted to observe the model's training and validation performance. Finally, the trained LSTM model is used to predict the sentiment of sample movie reviews. This experiment demonstrates how LSTM networks can effectively process text sequences and perform sentiment classification.
